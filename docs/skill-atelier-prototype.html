Skill Atelier 匠心技能工坊 v0.1.0 · Apache-2.0
个人元技能制造与治理系统：围绕你的真实任务、工作记录和使用反馈，持续发现 → 设计 → 制造 → 验证 → 维护 → 退役 Agent Skills。 它不是"批量生成 SKILL.md 的生成器"，而是维护你整座个人技能库的工厂。

三、交互命令 /atelier
discover — 从任务/记录发现候选
design <目标> — 出设计文档，不建文件
build <目标> — 生成可运行技能
validate <路径> — 校验合规与安全
improve <路径> — 按反馈迭代
deprecate <路径> — 判定并安全退役
audit — 全库审计（重叠 / 失效 / 低价值）
四、npx CLI（零依赖 Node 薄壳）
build — 生成技能骨架
validate — 校验技能
audit / dup — 技能库查重
usage — 使用日志分析
bump — 版本升级
help / version
discover / design / improve / deprecate 为智能体驱动流程，交给元技能本体。
五、八条操作原则
1 从证据出发，不从想象出发 2 一个技能一个窄职责 3 制造可执行、可测试的产物 4 保留个人风格与约束 5 声明触发场景与非目标 6 不为凑数保留资源 7 验证通过才算完成 8 用退役代替堆积
