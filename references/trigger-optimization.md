# 触发描述优化

> 来源：agentskills 官方 optimizing-descriptions 指南。用于：描述互相抢触发、触发不准、该触发没触发。

## 1. 触发机制

- 启动时只加载所有技能的 **name + description**，凭它们决定是否激活；
- description 承担**全部触发负担**——没写清"何时用"，智能体就不会够到它；
- 简单一步请求（"读这个 PDF"）即使描述完全匹配也可能不触发——智能体自己就能干。需要专门知识的任务（陌生 API、领域流程、非常规格式）才是描述能起作用的地方。

## 2. 好描述四原则

1. **祈使句**："Use this skill when..."，不要说"本技能负责…"；
2. **聚焦用户意图**，不写内部实现——智能体是按"用户问了什么"匹配的；
3. **宁可外向**：明确列出适用语境，包括用户**没有点名领域**的情况（"即使他没提 CSV 或分析"）；
4. **简洁**：几句话到一个短段落；硬上限 1024 字符。

## 3. 设计触发评估查询集

约 **20 条查询**：8–10 条应触发 + 8–10 条不应触发。

**应触发**（测试描述是否覆盖范围）——在多个轴上变化：
- 措辞：正式/随意/带错别字或缩写；
- 显式度：直接点名领域 vs 只描述需求不点名；
- 细节：一句话 vs 带文件路径、列名、前因后果的长消息；
- 复杂度：单步 vs 埋在大流程里的多步。

最有价值的应触发用例是"**技能能帮忙但查询里看不出联系**"的——这才是措辞决定成败的地方。

**不应触发**（测试是否精确）：最有价值的是 **near-miss（近失）**——共享关键词但需求不同：
- 弱负例：`写个斐波那契函数`（毫不相关，测不出东西）；
- 强负例：`更新我 Excel 预算表的公式`（共享"表格/数据"概念但需要的是 Excel 编辑）。

**真实感**：带文件路径（`~/Downloads/report_final_v2.xlsx`）、个人上下文（"我老板让我…"）、具体列名/公司名/数值、口语和缩写。

## 4. 测试触发率

- 每条查询跑 **3 次**（模型不确定），算触发率 = 触发次数/运行次数；
- 应触发通过线：触发率 > 0.5；不应触发通过线：触发率 ≤ 0.5；
- 能早停就早停：要么查了技能、要么开始干活了，结果已定。

## 5. 训练/验证切分（防过拟合）

- **训练集（60%）**：用来找失败、指导改进；
- **验证集（40%）**：留起来，只在最后检查改进是否泛化；
- 两边都要正负例比例均匀；随机打乱后**固定切分**，保证各轮可比。

## 6. 优化循环（最多约 5 轮）

1. 在训练+验证集上评估当前描述；
2. 只看**训练集**失败：哪些应触发的没触发？哪些不应触发的触发了？
3. 修改描述：
   - 应触发失败 → 描述太窄：扩范围或补适用语境；
   - 不应触发误触发 → 描述太宽：加"不做什么"的边界；
   - **禁止把失败查询的具体关键词抄进描述**——那是过拟合；要提炼背后的**一般类别**；
   - 卡住多轮 → 换描述结构，别继续增量调参；
   - 随时检查 ≤1024 字符（描述会在优化中变长）。
4. 重复到训练集全过或无明显改进；
5. 用**验证集通过率**选最优迭代——最好的可能是早期版本，后期可能过拟合训练集。

## 7. 应用结果

1. 更新 frontmatter 的 description；
2. 验证 ≤1024 字符；
3. 手测几条 + 写 5–10 条全新查询（从未参与优化）跑一遍——诚实检验泛化。

## 8. 前后对照

```yaml
# 之前
description: Process CSV files.
# 之后
description: >
  Analyze CSV and tabular data files — compute summary statistics,
  add derived columns, generate charts, and clean messy data. Use this
  skill when the user has a CSV, TSV, or Excel file and wants to
  explore, transform, or visualize the data, even if they don't
  explicitly mention "CSV" or "analysis."
```

改进后：做什么更具体（统计、派生列、图表、清洗），何时用更宽（CSV/TSV/Excel、即使不提关键词）。

## 9. 本工坊落地

- 评估查询集保存为 `eval_queries.json`（`[{"query": "...", "should_trigger": true}]`），放技能目录或 `drafts/`；
- 触发优化归 `skills/atelier-validate` 负责；
- 描述互相抢触发时，先跑 `scripts/detect_duplicates.py` 看重叠面再动手。
